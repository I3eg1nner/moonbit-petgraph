## 2. 测试分层策略

### 2.1 黑盒测试(`*_test.mbt`)
仅通过公开 API 进行测试,模拟真实使用者的视角。每个公开函数至少有一个黑盒用例。
断言统一使用 `debug_inspect(value, content=...)` 与 `json_inspect(arr, content=[...])`;
快照内容先以 `moon test --update` 生成,再**逐一对照 petgraph 语义人工核验**,绝不盲目
接受工具生成的输出。

### 2.2 白盒测试(`*_wbtest.mbt`)
深入包内部,校验公开 API 无法直接观测的**表示不变量(representation invariant)**:

- `graph`:每次 `remove_node` / `remove_edge`(采用 swap-remove + 链接修补)之后,
  邻接链表仍保持自洽 —— 每个结点的 `next_out` / `next_in` 链都能终止于哨兵 `END`,
  不存在悬空的 `EdgeId`,每条边的 `src` / `dst` 与其在邻接表中的位置一致。覆盖删除
  中间结点(触发交换)、删除末尾结点、自环、多种边删除顺序、无向图等场景。
- `unionfind`:路径压缩与按秩合并后的 `parent` / `rank` 数组内部状态。

### 2.3 快照测试(DOT 输出)
DOT 渲染结果与 petgraph 自带测试模块中的**黄金字符串**逐字节比对,保证有向 `->` /
无向 `--`、转义、结点/边标签的格式完全一致。

### 2.4 属性式交叉验证
用确定性构造的图,验证对**任意输入**都应成立的性质(详见 §4):例如非负权图上
`dijkstra` 与 `bellman_ford` 结果一致、DAG 上拓扑序尊重每条边、Kosaraju 与 Tarjan
的 SCC 数量与内容一致等。

### 2.5 文档即测试(`README.mbt.md`)
`README.mbt.md`(已软链到仓库根的 `README.md`)中的代码块以 ```` ```mbt check ````
形式被编译并执行,确保 README 中的示例永远与真实 API 同步、**可复现**。

## 3. 测试用例清单(共 75 项)

### 3.1 `graph` 包(20)
**黑盒(15):**
1. construction: directed vs undirected, counts —— 构造与计数
2. add nodes and edges, weights and endpoints —— 增点/增边、权重、端点
3. update_edge updates existing, adds new —— 已存在则更新、否则新增
4. find_edge directed and undirected —— 有向/无向边查找
5. node_ids and edge_ids —— 结点/边 id 枚举
6. neighbors order: reverse insertion, directed —— 邻居为逆插入序
7. neighbors are reverse-insertion order —— 逆插入序(补充)
8. neighbors undirected and self-loop skip —— 无向邻居与自环跳过
9. edges_directed order —— 出/入边顺序
10. externals —— 无出(入)边的结点
11. remove_node returns weight and removes incident edges —— 删点
12. remove_edge returns weight and keeps structure —— 删边
13. from_edges directed auto-creates nodes —— 由边列表构图(有向)
14. from_edges_undirected —— 由边列表构图(无向)
15. reverse flips edge direction;clear and clear_edges —— 反向 / 清空

**白盒(5):**
16. invariants after remove middle node (forces swap) —— 删中间结点触发交换后的不变量
17. invariants after remove last node —— 删末尾结点
18. invariants after several remove_edge orderings —— 多种删边顺序
19. invariants with self loops, then remove —— 自环后删除
20. invariants on undirected graph after removals —— 无向图删除后不变量

### 3.2 `unionfind` 包(14)
**黑盒(10):** new sets are disjoint singletons;union merges and find agrees;
union return value reflects whether a merge happened;same_set (equiv);long chains
collapse to a single set;into_labeling(单集合与多不相交集合各一);incremental
new_set;try_* out of bounds;structured larger scenario(成对 union 与 find 一致)。
**白盒(4):** new initializes parent[i]=i and rank[i]=0;find applies path compression
(halving);union by rank(等秩抬升根的秩 / 小树挂大树)。

### 3.3 `visit` 包(11)
- Dfs preorder / Bfs / DfsPostOrder / Topo 在样例 DAG 上的精确访问顺序
- Dfs reset and move_to —— 重置与重定位
- Topo skips nodes on a cycle —— 拓扑遍历跳过环上结点
- depth_first_search:发出 discover/finish 与 tree edge;检测回边;`Break` 提前终止;
  `Prune` 跳过某结点的出边

### 3.4 `dot` 包(8)
有向图(int 权)、无向图(`graph` 关键字与 `--` 边)、`EdgeNoLabel`、`NodeNoLabel`、
`NodeIndexLabel`、`EdgeIndexLabel`、`GraphContentOnly`、引号/反斜杠/换行的转义。

### 3.5 `algo` 包(19)
- **dijkstra:** 单位权(petgraph 文档示例)、带权且指定 goal 提前终止
- **astar:** 最优路径(petgraph 文档示例)、无路径返回 None
- **bellman_ford:** 距离与前驱(petgraph 文档示例)、检测负环
- **toposort:** DAG 上每条边 source 先于 target、有环返回 Err
- **环检测:** is_cyclic_directed 当且仅当 toposort 为 Err、is_cyclic_undirected(并查集)
- **连通分量:** connected_components 统计无向连通块
- **SCC:** kosaraju(DAG 各自成 SCC、双环图逆拓扑序)、tarjan(逆拓扑序、与 kosaraju 一致)
- **MST:** Kruskal 选取最轻生成森林边、非连通图得到森林
- **交叉验证:** dijkstra == bellman_ford(非负权)、connected_components == 对称图的
  kosaraju SCC 数

### 3.6 根包文档示例(3)
shortest path and spanning tree、dot export、traversal and cycles。

## 4. 重点:属性式交叉验证

这些用例不依赖单一"标准答案",而是用一个算法的结果验证另一个算法,显著提升可信度:

| 性质 | 含义 |
|------|------|
| `dijkstra` ≡ `bellman_ford` | 非负权图上两种最短路算法的距离逐点相等 |
| `toposort` 尊重边序 | 随机 DAG 上,排序结果中每条边的 source 都排在 target 之前 |
| `is_cyclic_directed` ⇔ `toposort` 为 `Err` | 对包含自环在内的多个图均成立 |
| `tarjan_scc` ≡ `kosaraju_scc` | 同一有向图上两种 SCC 算法的数量与内容一致 |
| `connected_components` ≡ kosaraju SCC 数 | 对称(双向)有向图上无向连通块数等于其 SCC 数 |

```bash
export PATH="$HOME/.moon/bin:$PATH"   # 若 moon 不在 PATH 中

moon test                  # 默认后端(wasm-gc)运行全部测试
```

## 7. 测试中发现并修复的真实缺陷

测试不是走过场,过程中确实暴露并修复了实现缺陷,典型如下:

1. **`kosaraju_scc` 返回空结果(降序 range 不迭代)。**
   MoonBit 的区间 `for x in a..=b` 仅支持升序,`(len-1)..=0` 这类降序写法**根本不会
   迭代**。这导致 Kosaraju 第二趟按完成时间逆序处理结点的循环空转,SCC 结果为空。
   修复:改用显式递减的 `for` 循环。该缺陷正是被"tarjan 与 kosaraju 必须一致"这条
   交叉验证用例抓出来的。

2. **`Show` → `Debug` 迁移导致的快照差异。**
   当前 MoonBit 工具链正从 `Show` 迁移到 `Debug` 作为调试输出。`debug_inspect` 会给
   字符串加引号(`Some("b")`),而旧的 `Show` 不加(`Some(b)`)。统一改用
   `derive(Debug)` + `debug_inspect` 后,相应快照同步更新并核验。

3. **DOT 字符串断言方式。**
   多行 DOT 字符串若用 `debug_inspect` 会被转义成单行,改用 `assert_eq` 对照 `#|`
   多行字符串字面量(末尾补一个空 `#|` 行以匹配结尾换行)。

## 8. 确定性与可复现性说明

- **邻居顺序**遵循 petgraph 的**逆插入序**(侵入式链表头插)。凡比较邻居/遍历序列的
  用例,要么期望该精确顺序,要么先排序再断言。
- **SCC 分量内部**结点顺序是任意的;比较前会对内部数组排序,使输出在不同运行/后端
  之间稳定。
- 随机性测试使用确定性的小型种子生成器,不引入外部 quickcheck 依赖,保证可复现。

`*_ported_test.mbt` 文件中。移植来源:petgraph 的 `tests/*.rs`、`src/algo/*` 与
`src/graph_impl/mod.rs` 的内联 `#[test]`/doctest。

### 9.2 移植时的适配(因语言/API 差异)

忠实移植但需对接 MoonBit API,典型适配:

- **`Option` vs `Result` / panic 索引:** petgraph 用 `g[idx]` 直接索引、`try_*` 返回
  `Result`;本项目 `node_weight`/`edge_weight` 返回 `Option`,`try_*` 返回 `Option`。
- **迭代器 vs 物化数组:** petgraph 的 `neighbors(n).count()`、`walker.iter(&g)` 改为本项目的
  `neighbors(n).length()`、循环 `walker.next(g)`。
- **MST 返回形态:** petgraph 返回元素流/新图;本项目返回 `Array[EdgeId]`,改为校验"边数 =
  结点数 − 连通分量数"且 MST 总权重一致。
- **SCC 顺序:** 两者均为逆拓扑序、SCC 内部顺序任意,比较前规范化(对内部与外层都排序),
  对应 petgraph 自己的 `assert_sccs_eq`。
- **`Ix` 泛型坍缩为 `Int`:** petgraph 的 `_u8`/`_u16`/`_u32` 索引宽度变体在本项目中等价,
  合并为单个 `Int` 用例(已注明)。
- **随机性:** `uf_rand` 等用确定性 LCG 替代 Rust 的 rng,保留"大量随机 union 后校验一致性"
  的意图。
- **`debug` 路径:** 对 `Int?` 等只派生 `Show` 的组合类型,用 `json_inspect` 或布尔
  `is Some(..) && ..` 断言,避免触发 `Show`-用于调试的弃用告警,断言意图不变。

### 9.3 有意跳过的 petgraph 测试(超出本项目范围)

以下 petgraph 测试**不在本次移植范围**,已逐项记录原因(范围见 [`DESIGN.md`](./DESIGN.md)):

- **依赖未实现的算法/适配器:** 使用 `algo`/`visit` 之外功能或 `Reversed`/`NodeFiltered`/
  `EdgeFiltered` 适配器的测试(如 `filtered*`、`filtered_post_order`、`test_dominators_*`)。
- **未实现的图操作:** `raw_nodes`/`raw_edges`、`into_nodes_edges`、`retain_*`、容量/`reserve`/
  `shrink_*`、权重迭代器(`node_weights_mut` 等)、`edges_connecting`、`first_edge`/`next_edge`、
  `map`/`filter_map`/`from_elements`、`index_twice_mut`/detach walkers。
- **范围外数据结构:** `StableGraph`、`GraphMap`、`degree_sequence`、序列化、`Frozen`。
- **范围外算法:** spfa、floyd_warshall、johnson、k_shortest_path、page_rank、bridges、
  articulation_points、matching、最大流(dinics/ford_fulkerson)、dominators、coloring、
  同构(iso)、steiner、feedback_arc_set、**condensation**(SCC 凝聚图)、prim(专用变体;
  相同图已由 Kruskal 覆盖)。
- **索引宽度/容量/溢出与 panic:** `oob_index`、`u8_index_overflow*`、`test_try_add_node/edge`
  —— `Ix` 坍缩为 `Int` 后这些变体合并或不适用(无 `GraphError`/溢出 API)。
- **`generate` feature 的图生成器测试** 与纯 quickcheck 测试 —— 以确定性构造替代或跳过。

### 9.4 移植结论

**58 个移植用例全部一次性通过,未发现任何实现缺陷** —— 即在这些 petgraph 真实测试覆盖的
行为上,本 MoonBit 移植与原版**逐点一致**。这为"行为保真"提供了强有力的旁证(尤其是
有向/无向的逆插入邻居序、`update_edge` 合并语义、SCC 划分、最短路数值等细节)。
