# 申报书草案 — petgraph for MoonBit

> 草案，供参赛者本人核对后提交。

- **项目名称**：petgraph for MoonBit（模块名 `I3eg1nner/petgraph`，发布账号与仓库属主 `V1GreenSummer` 同属一人）
- **项目仓库**：https://github.com/V1GreenSummer/moonbit-petgraph
- **项目性质**：**移植**。上游为 Rust 的 [petgraph](https://github.com/petgraph/petgraph)（MIT OR Apache-2.0）。本项目为 MoonBit 重新实现，未复制任何 Rust 源码；参考范围、许可与归属见 [`docs/THIRD_PARTY.md`](THIRD_PARTY.md)。

## 项目简介与方向

方向：**基础数据结构与算法库**。为 MoonBit 生态补齐一个通用图库：以邻接表 `Graph[N, E]` 为核心，支持有向/无向图与任意节点、边权类型，提供 35 个图算法与 Graphviz DOT 导出。

## 目标场景

依赖分析与构建调度（拓扑排序、环检测、支配树）、路径规划与网络分析（最短路、最大流、连通性）、编译器与静态分析（SCC、支配边界、传递归约）、以及任何需要在 MoonBit 中表达图结构的应用。

## 核心功能

1. **`@graph`**：邻接表图，侵入式边链表，`swap_remove` 语义；`map`/`filter_map`/`retain_*` 变换、`EdgeRef` 边引用迭代。
2. **`@visit`**：`Dfs`/`Bfs`/`DfsPostOrder`/`Topo`、事件式 `depth_first_search`，以及 `Reversed`/`NodeFiltered`/`EdgeFiltered`/`UndirectedAdaptor` 视图适配器——它们实现同一个 `NeighborSource` trait，因此可与全部遍历和结构算法自由组合。
3. **`@algo`**：最短路（Dijkstra、A\*、Bellman-Ford、SPFA、双向 Dijkstra、k 最短路、Floyd-Warshall、Johnson）、连通性（SCC、割点、桥、支配树、缩点、二分图判定）、生成树与 Steiner 树、最大流（Ford-Fulkerson、Dinic）、匹配（贪心与 Gabow blossom）、着色、极大团、简单路径枚举、反馈弧集、DAG 传递归约。
4. **`@unionfind`**：按秩合并 + 路径压缩的并查集。
5. **`@dot`**：Graphviz DOT 导出。

## 实施方案

分阶段依赖驱动推进：先落地 `graph` 与 `unionfind` 两个叶子包，再叠加 `visit`/`dot`，最后是 `algo`。每个算法直接对照上游 Rust 源码移植，并同步移植上游自身的测试用例（`*_ported_test.mbt`，保留原始 Rust 测试名）以验证行为一致。
